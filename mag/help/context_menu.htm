Context Menu

Right-click MAG's frame or tray icon to open the context menu. The active view mode is checked. Window, Follow Mouse, and Lens are mutually exclusive. The menu is a single flat command list; Help navigation is inside the compiled Help viewer.

The complete MAG context menu, captured from the application on an isolated Windows desktop.

ItemDescription
Window Anchors capture to MAG's screen position. At 1.0×, the source aligns with the desktop behind MAG unless minimap panning has pinned another source origin.
Follow Mouse Keeps MAG stationary while centering the captured source on the pointer. MAG remains interactive; press Space to return to Window mode.
Lens Moves MAG with the pointer as a topmost, non-activating, click-through lens. Pointer input reaches the application below and overlay controls are disabled.
Settings... Opens the complete renderer, capture, UI, text, presentation, composition, copy-policy, alpha, pacing, and adapter configuration dialog. See Settings Reference.
Help Opens the complete compiled Help viewer. Use its Contents, Index, and Search tabs to navigate every topic.
Exit Closes MAG, removes its tray icon, closes Help windows, and releases active graphics/capture resources.

The Help command opens this compiled CHM viewer. Use the left navigation pane; no Help submenus are added to MAG's context menu.

Find a setting or API

Select Index and type the first letters of the feature, such as DWM Private Visual, Direct3D 12, or Strict zero-copy.
Select the matching term to open its primary topic.
Use Search when you need every topic/source page containing a phrase or status message.
