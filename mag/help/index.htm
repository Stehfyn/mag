MAG Screen Magnifier

MAG is a native Windows magnifier with independently selectable capture, graphics, UI, text, presentation, composition, surface, copy-policy, and adapter paths. It renders during interactive move and resize and activates each compatible setting change immediately.

Start here Leave presentation fields on Auto, choose a capture and graphics API, and read Configuration status before changing exact-target or copy-policy requirements.

Quick start

Move and resize: drag the frame, an edge, or a corner. MAG updates the visible frame while the modal move/resize loop is active.
Zoom: rotate the mouse wheel over MAG. Enable mouse-relative wheel zoom in Settings when the desktop point beneath the pointer should stay fixed.
Choose behavior: right-click MAG's frame or tray icon and select Window, Follow Mouse, or Lens.
Choose a pipeline: open Settings, select rendering/capture, then use Auto presentation choices until a specific Windows model is required.
Read the route: the Settings DAG shows the active capture-to-display pipeline. Every node is interactive; unavailable choices show their reason without replacing the working route.

Core interaction: wheel to zoom, frame to move, edges/corners to resize, and the minimap source rectangle to pan.

Open MAG commands and Help

MAG context menu: one flat list for the three modes, Settings, Help, and Exit. The current mode is checked.

Compiled Help: Contents provides the guided structure; Index locates named APIs/features; Search covers every topic and embedded source page.

System requirements

  • Windows 10 or later and a graphics driver supporting the selected API.
  • Windows 11 runtime support when Presentation Manager is selected.
  • Runtime availability for the selected capture API, compositor path, adapter, output, session, and desktop.
  • A compatible render/display adapter relationship for routes that cannot cross adapters without a copy.
DWM Private Visual: MAG retains a DWM shared desktop source plus positioned per-window visuals for desktop, taskbar, and application content. MAG applies zoom and pan to an app-owned wrapper visual and publishes geometry atomically. See Windows Graphics Architecture.
